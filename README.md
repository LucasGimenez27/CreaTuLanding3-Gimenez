# Tienda Marolio
Este es un proyecto de e-commer basico que se utiliza para el curso de React. La plaicacion permite ver una lista de productos se supermercado y realizar compras en linea. Loas productos y las ordenes de compra se almacenan en Firebase.

## Tecnologías utilizadas
- Vite
- React
- React-Router-DOM
- Firebase
- Toastify
- React Bootstrap

## Funcionalidades
- Ver una lista de productos disponibles segun stock
- Agregar productos al carrito de compras
- Ver el carrito de compras
- Realizar una orden de compra
